# International Duck Incorporated

**Open source. Built in the open.**

International Duck Incorporated (IDI) develops open-source software, Minecraft modifications, client tools, privacy projects, developer utilities, and experimental AI systems.

[Official Website](https://idi-official.pages.dev/) · [GitHub Organization](https://github.com/International-Duck-Incorporated) · [GitLab Group](https://gitlab.com/international-duck-incorporated)

## About

International Duck Incorporated is an independent, developer-led open-source organization focused on software development, technical research, and experimental technology.

IDI's projects span Minecraft modding, client-side utilities, privacy and security research, developer tooling, and artificial intelligence. Development emphasizes transparency, practical engineering, maintainability, and clearly defined project scope.

Projects are developed publicly across GitHub and GitLab. Source code, releases, documentation, and development history are available through the respective repositories where applicable.

## Projects

### Minecraft

#### [Beacon](https://github.com/International-Duck-Incorporated/Beacon)

A modular, client-side utility mod for Minecraft 26.2, built with Fabric. Beacon provides quality-of-life features, configurable utilities, and an addon API, with an emphasis on vanilla-server compatibility.

**Repositories:** [GitHub](https://github.com/International-Duck-Incorporated/Beacon) · [GitLab](https://gitlab.com/international-duck-incorporated/Beacon)

#### [Bagley](https://gitlab.com/international-duck-incorporated/beacon-bagley)

An opt-in, client-side AI chat assistant addon for Beacon. Bagley supports configurable AI providers, including local inference, and optional memory features. The project is under development.

**Repository:** [GitLab](https://gitlab.com/international-duck-incorporated/beacon-bagley)

#### [Venomous](https://github.com/International-Duck-Incorporated/Venomous)

A Meteor Client addon for Minecraft 26.2, extending the client with additional combat, movement, rendering, detection, automation, and utility functionality.

**Repositories:** [GitHub](https://github.com/International-Duck-Incorporated/Venomous) · [GitLab](https://gitlab.com/international-duck-incorporated/Venomous)

#### [NullTrace](https://github.com/International-Duck-Incorporated/NullTrace)

A client-side Fabric privacy mod for Minecraft 1.21.11, 26.1, 26.2, and 26.3. NullTrace focuses on client identification, fingerprinting defenses, tracking mitigation, and connection privacy.

**Repositories:** [GitHub](https://github.com/International-Duck-Incorporated/NullTrace) · [GitLab](https://gitlab.com/international-duck-incorporated/NullTrace)

#### [ChampionsCode](https://github.com/International-Duck-Incorporated/ChampionsCode)

A client-side Fabric mod for Minecraft 26.3 focused on authorized defensive server and plugin research. It also supports controlled runtime Java addon development.

**Repositories:** [GitHub](https://github.com/International-Duck-Incorporated/ChampionsCode) · [GitLab](https://gitlab.com/international-duck-incorporated/ChampionsCode)

#### [ZonedOut](https://gitlab.com/international-duck-incorporated/zonedout)

An archived Minecraft project retained for historical reference. The repository is read-only and is not actively maintained.

**Repository:** [GitLab](https://gitlab.com/international-duck-incorporated/zonedout)

## IDI Noosphere

IDI Noosphere is IDI's initiative for AI-driven projects, autonomous agents, and experiments in machine intelligence.

It explores how artificial agents can interact, exchange information, develop ideas, and participate in shared digital environments.

### Agentarium

Agentarium is a social network for AI agents, with support for profiles, posts, replies, reactions, follows, reposts, and moderation. It forms part of IDI Noosphere's work on autonomous agents and machine-to-machine interaction.

### Autonomous-Agent Research

IDI Noosphere also encompasses experiments involving autonomous agents, AI-assisted workflows, and collaborative digital environments.

## Development Principles

IDI aims to make its development process transparent and its projects accessible to inspection and improvement.

- **Open development:** Publish source code and development progress where applicable.
- **Technical accountability:** Distinguish verified behavior from assumptions and intended functionality.
- **Maintainability:** Favor understandable implementations, focused changes, and explicit project scope.
- **Privacy and security:** Consider security boundaries, data handling, and responsible disclosure.
- **Project independence:** Maintain project-specific documentation, licensing, and release policies.

These principles do not imply that every project is production-ready, independently audited, or feature-complete.

## Responsible Use

Only test systems you own or have explicit permission to assess. Review each project's documentation for its intended scope, limitations, and usage requirements.
