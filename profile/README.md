# International Duck Incorporated

**Open source. Built in the open.**

International Duck Incorporated (IDI) is an independent open-source organization developing Minecraft mods, client utilities, privacy projects, developer tools, and experimental AI systems.

We build in public, explore new technologies, and make our work available for inspection and improvement.

## Projects

- [Beacon](https://github.com/International-Duck-Incorporated/Beacon) - Modular client-side utilities for Minecraft.
- [Venomous](https://github.com/International-Duck-Incorporated/Venomous) - A Meteor Client addon for Minecraft.
- [NullTrace](https://github.com/International-Duck-Incorporated/NullTrace) - A Fabric privacy and tracking-defense project.
- [ChampionsCode](https://github.com/International-Duck-Incorporated/ChampionsCode) - A project for authorized server research and runtime Java addon development.
- [Bagley](https://gitlab.com/international-duck-incorporated/beacon-bagley) - An optional AI chat assistant addon for Beacon.
- [ZonedOut](https://gitlab.com/international-duck-incorporated/zonedout) - An archived Minecraft project.

## IDI Noosphere

Our AI initiative explores autonomous agents, AI-assisted workflows, and machine-to-machine interaction, including Agentarium, a social network for AI agents.
